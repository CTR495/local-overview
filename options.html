Local by design

No telemetry, accounts, ads, or remote AI services.

Your search query goes to the local Ollama endpoint when you generate an answer. If you enable search grounding, a limited set of publicly visible result titles, links, and snippets goes with it. Answers and queries are not saved by this extension.

Google still receives your searches. Local Overview does not make Google Search private or offline. Local models can make mistakes; verify important answers against the sources.

Connection setup & troubleshooting

Install Ollama from ollama.com, start it, then download a local chat model in your terminal:

ollama pull llama3.2:3b

If the connection is blocked with HTTP 403, allow this extension’s exact origin using Ollama’s OLLAMA_ORIGINS environment variable, then restart Ollama.

Use the exact origin above. Avoid allowing every website or exposing Ollama on your network. See the README for platform-specific steps.

If no models appear, download a local chat model and click Retry. Embedding-only models cannot generate chat answers. Cloud-backed models are not supported.
